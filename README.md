# Bank Simulation

## About
Basic bank simulation made with Java. It uses simple `JOptionPane` windows for input and output.

## Features
- Create account
- Deposit money
- Withdraw money
- Check balance
- Transfer money
- Show accounts

## Technologies
- Java
- ArrayList
- OOP
- JOptionPane (Swing)

## How to Run
```bash
javac src/*.java -d out
java -cp out Main
```

## Purpose
This project was created to practice basic Java and Object-Oriented Programming.
